# REL-603 — 연령대별 수동 사용성 실사

```text
REL = REL-603
STATUS = HUMAN_BLOCK
AUTOMATION_LEVEL = A0
HUMAN_EXECUTED = 0
PARTICIPANTS_REQUIRED = 9
PARTICIPANTS_RECRUITED = 0
RESULT_ROWS_COMPLETE = 0
ACCEPTANCE_MET = 0
FAKE_PASS = 0
PROTECTED_SCOPE_MUTATION = 0
NEXT_ACTION = Founder recruits and runs 20s/40s/60-70s participants, 3 per age band
```

## 1. 목적과 범위

Release Master의 REL-603 요구 그대로, **20대 / 40대 / 60–70대 각 3명, 총 9명**이 실제 퍼뜩 흐름에서 길을 잃는지 사람이 관찰한다.

- 사람 실행 필수. 에이전트·스크립트·자동 브라우저로 대체하지 않는다.
- 이번 문서는 실사 시나리오와 기록 형식을 준비하는 문서이며, 현재 상태 자체는 PASS가 아니다.
- 범위는 `가입 → 기회 확인 → 참여 → 지갑 확인`의 사용자 여정이다.
- 참가자에게 정답 경로를 먼저 설명하지 않는다. 관찰자가 개입했다면 반드시 기록한다.
- P0가 발견되면 해당 기능을 소유한 REL을 재오픈 대상으로 표시한다.

기기/브라우저는 실제 사용 환경을 결과표에 기록하되 특정 기기를 강제하지 않는다.

## 3. 진행 원칙

1. 참가자에게 “퍼뜩에서 처음부터 시작해 아래 목표를 달성해 달라”고만 안내한다.
2. 관찰자는 클릭 위치를 지시하거나 다음 화면을 알려주지 않는다.
3. 참가자가 스스로 멈추거나 도움을 요청하면 그 시점과 이유를 기록한다.
4. 직접적인 안내가 필요했다면 `관찰자 개입 = Y`로 기록한다.
5. 자동화 결과, 기존 E2E PASS, 개발자 지식으로 사람 결과를 대신하지 않는다.
6. 동일한 핵심 시나리오를 9명에게 사용한다.

## 4. 공통 시나리오 시트

### S1. 가입 / 시작

**목표:** 처음 방문한 사용자가 가입 또는 로그인 진입점을 찾고, 서비스 사용을 시작할 수 있는 상태까지 이동한다.

관찰 항목:
- 첫 화면에서 무엇을 해야 하는지 스스로 이해하는가
- 가입/로그인 진입점을 찾는가
- 화면의 용어 때문에 멈추거나 뒤로 가는가
- 다음 단계가 무엇인지 질문하는가

### S2. 기회 확인

**목표:** 사용 가능한 기회 목록에서 하나를 열고, 무엇을 하는 기회인지 이해한다.

관찰 항목:
- 기회 목록을 찾는가
- 카드/상세에서 예상 수익, 예상 시간, 참여 조건을 이해하는가
- “무엇을 하면 되는지”를 자기 말로 설명할 수 있는가
- 잘못된 CTA나 다른 메뉴로 반복 이동하는가

### S3. 참여

**목표:** 선택한 기회의 참여 흐름을 시작하고 확인 단계까지 진행한다.

관찰 항목:
- 참여 CTA를 자연스럽게 찾는가
- 확인 화면/모달의 의미를 이해하는가
- 참여 결과나 다음 상태를 오해하지 않는가
- 되돌아가거나 중복 행동을 시도하는가

### S4. 지갑 확인

**목표:** 지갑으로 이동해 현재 자산/거래 관련 정보를 확인한다.

관찰 항목:
- 지갑 진입점을 찾는가
- 주요 금액과 상태를 구분하는가
- 입금/출금/내역의 차이를 이해하는가
- 실제 돈 관련 행동을 하지 않아도 어디서 무엇을 확인하는지 설명할 수 있는가

## 5. 이슈 심각도 기록 기준

| 심각도 | 기록 기준 | 처리 |
|---|---|---|
| `P0` | 핵심 여정을 진행할 수 없거나, 참여/금액/상태를 중대하게 잘못 이해하여 안전하게 진행할 수 없음 | 해당 소유 REL 재오픈 대상으로 즉시 표시 |
| `P1` | 관찰자의 직접 안내 없이는 핵심 여정을 완료하지 못하거나 핵심 의미를 크게 오해함 | 수정 후보로 기록 |
| `P2` | 혼란·지연·우회가 있었지만 스스로 회복하여 목표를 완료함 | 개선 후보로 기록 |
| `P3` | 핵심 진행에는 영향이 작은 문구·배치·표현 불편 | polish 후보로 기록 |

심각도는 자동 계산하지 않는다. 관찰 사실을 먼저 적고 사람이 판정한다.

## 8. 완료 판정

REL-603을 완료했다고 기록하려면 다음 사실이 모두 있어야 한다.

- 9명 전원의 실제 사람 실행 결과가 결과표에 존재한다.
- 20대 / 40대 / 60–70대가 각각 3명이다.
- 네 시나리오의 관찰 결과와 관찰자 개입 여부가 기록되어 있다.
- 발견 이슈가 심각도별로 기록되어 있다.
- P0가 있으면 해당 소유 REL 재오픈 대상이 명시되어 있다.
- 실제 실사 없이 자동화 결과만으로 `STATUS = COMPLETED` 또는 `ACCEPTANCE_MET = 1`을 만들지 않는다.

## 9. 현재 HUMAN_BLOCK

현재 이 문서를 만든 시점에는 실제 참가자 9명의 실행 결과가 제공되지 않았다. 따라서 현재 truth는 다음과 같다.

```text
STATUS = HUMAN_BLOCK
HUMAN_EXECUTED = 0
PARTICIPANTS_RECRUITED = 0
RESULT_ROWS_COMPLETE = 0
ACCEPTANCE_MET = 0
FAKE_PASS = 0
BLOCK_REASON = 9 human participants have not been recruited/executed yet
```

이 HUMAN_BLOCK은 실패를 숨기기 위한 PASS가 아니라, Release Master가 허용한 정직한 인간 실행 게이트 기록이다.
